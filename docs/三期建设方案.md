# 多项目 Agent 管理平台 · 三期建设方案

> 版本：v1.0　日期：2026-11-05
> 前序：一期（DDP `docs/109`）、二期（DDP `docs/111`/`112`/`113`）

## 执行规则（用户已定）

1. 一期、二期正式标记为**已完成**，作为现有系统能力与架构基线，不再重复建设。
2. 三期是**唯一当前实施阶段**，所有研发任务、Agent 分工和验收围绕三期展开。
3. 已有系统**全部保留**：代码、数据库、接口、UI、运行环境不做无必要推倒重建。
4. 未来架构：从 Agent 管理平台 → 具备自主调度、跨项目协作、运行时控制、移动端指挥的智能研发管理平台。

## 用户已确认的三个边界

| 决策 | 选择 |
|---|---|
| 自主调度层次 | 全自动执行（平台起进程） |
| 执行器权限 | **只读 + 改代码**：禁止 push / 部署 / 删数据 |
| 移动端形态 | 现有页面响应式改造 |
| 运行时控制 | 只读监测 + 一键操作（二次确认 + 审计） |
