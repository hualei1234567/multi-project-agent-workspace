# E2E-02 实现说明：物料系统健康检查接口

1. 复用 `backend/app/api/health.py` 中已注册的 `GET /health` 路由，保持无鉴权、无业务数据依赖，仅做轻量探活。
2. 健康判定以一次 `SELECT 1` 的数据库连通性检测为准，并为连接设置短超时，避免探活请求长时间阻塞。
3. 服务正常时返回 HTTP 200，响应体为 `{"status": "ok", "db": true}`；只输出状态字段，不暴露连接串、异常堆栈等敏感信息。
4. 依赖异常时返回 HTTP 503，响应体为 `{"status": "unhealthy", "db": false}`，便于容器编排、负载均衡与告警系统按状态码判定。
5. 版本等静态信息改为从应用配置读取，避免在路由中硬编码（现有 `version`、`approval` 字段需一并清理）。
6. 补充接口测试，覆盖数据库正常返回 200、数据库异常返回 503、响应体不含敏感字段三类用例，且不依赖外部网络。
7. 接口保持同步快速返回，不访问业务数据表，不新增鉴权、限流或缓存依赖。
