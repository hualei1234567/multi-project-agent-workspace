# E2E-03 联调说明：物料系统健康检查接口

1. 联调前先确认服务已按实现说明部署，`GET /health` 路由已注册且无需任何鉴权头即可访问。
2. 数据库正常时直接请求接口，验收点为 HTTP 200 且响应体恰为 `{"status": "ok", "db": true}`，多余字段（含 `version`、`approval`）均应视为不合格。
3. 模拟数据库异常（如断开连接或指向不可达实例）后再次请求，验收点为 HTTP 503 且响应体为 `{"status": "unhealthy", "db": false}`。
4. 对两种响应都要检查内容，确认不含连接串、账号密码、异常堆栈等敏感信息，接口也不读业务数据表。
5. 观察异常场景下的响应耗时，应受短连接超时约束并快速返回，不能出现长时间阻塞或挂起。
6. 联调以接口测试用例为基线，覆盖 200、503、敏感字段三类场景，且全程不依赖外部网络。
7. 建议同时用编排/负载均衡的探活配置实际打一次请求，确认能按状态码正确判定健康与不健康。
8. 若线上已有旧版响应字段的消费方，需在切换前确认其对 503 与字段裁剪的兼容性，避免监控误报。
