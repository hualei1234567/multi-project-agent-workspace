## 4. 遗留风险

| # | 风险 | 等级 | 说明与缓解 |
|---|---|---|---|
| R1 | 权限为二值模型 | 中 | 无角色、无项目级授权；持令牌远端可操作全部项目。当前仅本机使用，尾网暴露前需补 RBAC |
| R2 | 跨项目协作零业务使用 | 中 | 能力与测试齐备，但 `task_dependencies` / `shared_resources` 均 0 行。需真实场景验证 |
| R3 | 移动端未实机验证 | 中 | Tailscale 客户端 stopped，手机→8099 链路未跑过。鉴权与响应式代码已就绪 |
| R4 | 执行器仅验证过单一路径 | 中 | 只跑通「改代码」的最小任务；超时、并发、熔断未在真实环境触发过 |
| R5 | 成本未设上限 | 中 | 单次执行有轮数/超时限制，但无全局预算。建议后续加每日 token/金额上限 |
| R6 | DDP 8080 不可达 | 低 | 环境问题，非代码；运行时已正确报告为 down |
| R7 | 迁移只测过 v1→v3 / v2→v3 | 低 | 回滚路径有测试，但未在真实库上演练过降级 |
