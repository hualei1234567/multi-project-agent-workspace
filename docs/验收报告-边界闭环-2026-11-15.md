## 一、多用户并发 —— 改判「不适用」

**原状态**：未验证，未做并发压测

**处理**：
用户明确指示「该系统只我一个人使用」「只测功能是否正常使用即可」。
并发不是该系统的有效边界。

**但过程中发现并修复了一个真实配置缺陷**：

压测时 10 并发有 20% 请求 `Connection reset`。根因：
`ThreadingHTTPServer` 默认 `request_queue_size = 5`，listen backlog 太小。

修复：
```python
class _Server(ThreadingHTTPServer):
    daemon_threads = True
    request_queue_size = 128   # 默认 5 太小
    allow_reuse_address = True
```

修复后 10 并发：**50/50 成功**，P95 96ms。

> 这个修复对单用户也有价值：浏览器会并发发起多个请求（state + overview +
  静态资源），backlog 太小会有偶发 reset。

**结论**：并发不作为验收边界，但 backlog 缺陷已修。
