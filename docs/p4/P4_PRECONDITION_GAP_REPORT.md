## 4. 为什么不满足的两项不阻塞"完成 P4-M0"

V6.0 §30.2 对 P4-M0 的定义是「准入、现状基线、架构与范围**冻结**」，不是"修好所有安全问题"。安全阻断项在本阶段的作用是**进入 P4-M1 的 DoR 前置**：

- R19/R20/R22/R23 已进入 `P4_RISK_REGISTER.md` 并排定处理顺序（§3）。
- 它们构成 P4-M1 的 Definition of Ready：**未关闭不得开始 M1 的业务功能开发**。

因此本报告的建议是：**P4-M0 文档交付完成，但 P4-M1 的开工门槛仍未满足**，需用户同时批准范围并提供 §3 中的两项输入。
